# CONCETT – Concert Journaling Android Application

## Overview

CONCETT is an Android application designed to enable users to blog, document, and organize their concert experiences through a personalized digital journal. The application aims to revive long-form concert blogging by providing a platform where users can preserve, revisit, and share memories from live music events.

---

## Features

- Secure user authentication
- Concert blogging and journaling
- Full CRUD (Create, Read, Update, Delete) functionality
- Firebase integration
- SQLite database for local data storage
- Multilingual localization
- Card-based user interface
- Intuitive Android navigation and Activities

---

## Technologies

- Java
- XML
- Android Studio
- Firebase
- SQLite
